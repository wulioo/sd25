# sd25 - Seedance 2.5 电影级提示词编译引擎 (Cinematic Prompt Optimizer)

`sd25` 是一套专为 **即梦 / 豆包 Seedance 2.5 多模态视频生成大模型（DiT 扩散架构）** 打造的院线级提示词优化 Skill。

本工具将传统电影工业中顶级导演（**王家卫、大卫·芬奇、黑泽明、丹尼斯·维伦纽瓦、让-皮埃尔·梅尔维尔**）的视听语言，降维转译为模型能够精确理解的**“物理光学参数、空间几何遮挡与解剖学生理动作”**，彻底根除 AI 视频中常见的“塑料感、漂浮感、面瘫假人、广播体操式匀速动作与数码过饱和”。

---

## 🌟 核心特性

### 1. 顶级导演视听工程体系 (Cinematic Directorial System)
*   **王家卫式光影与微表情**：单点物理光源出处（2000K~6500K）、冷暖色温光场撕裂（Amber/Cyan）、水汽丁达尔漫反射；视线领先 0.2 秒（Eye-lead）、动作发起前的犹豫微悬停。
*   **大卫·芬奇式精密运镜**：机械重型滑轨、恒定速度平移与物理刹车阻尼（Damping），彻底消灭 AI 镜头眩晕乱晃。
*   **黑泽明式极端天气力学**：雨水在人脸的流淌渗湿、强风对织物的气动撕扯、深足泥泞的非牛顿流体黏滞阻力。
*   **丹尼斯·维伦纽瓦式巨物尺度**：特大全景（ELS）1:15 极值悬殊比例对比、单色大面积巨石负空间留白，营造史诗压迫感。
*   **梅尔维尔式战术工序仪式感**：动作的绝对经济性（Zero wasted motion）、点火避风护手、拔刀握柄指腹滑移入槽等高手肌肉记忆。

### 2. 算力保护：注意力预算定律 (Attention Budget Law)
每镜必须明确一个主要表现目标，并落实为可见或可听的导演处理。以下技法按**景别（Shot Scale）**与剧情条件选用，不是逐项必填；同一目标可由多种手段共同完成，尤其避免在 4~5 秒短镜头内堆砌无关处理：
*   **全局视觉与摄影处理**：遵守用户设定、参考职责与已锁定状态；单侧物理光源、35mm 胶片有机银盐颗粒、机械滑轨均为可选处理，先按镜头目的确定固定、移动或跟随；
*   **特写/近景 (CU/MCU)**：优先从【微表情 + 材质微观质感（包浆/毛孔透光）】中选用；
*   **中景交互 (MS)**：优先从【动作节拍顿挫 + 战术工序仪式感 + 物理重力与形变 + 拟音对位 <>】中选用，连续动作不强制插入蓄力或定格；
*   **全景空间 (WS/ELS)**：优先从【维伦纽瓦巨物尺度与负空间 + 空间几何纵深三层 + 黑泽明极端天气物理】中选用，不为套用技法新增巨物或天气。

### 3. 多模态：图文协同视听契约 (Image-Text Symbiosis)

**场景图在已采用的参考范围内优先**：沿用已采用的空间布局、环境状态、材质或光影；用户明确限定参考维度或要求改动时，以用户要求为准。未采用的维度不自动继承，普通场景参考不自动锁定机位与构图。动作、对白和事件顺序由剧本提供；明确指定构图、首帧或尾帧时按对应职责执行。

*   **“有图借势，无图自建；图定舞台骨架，文定时间灵魂”**；
*   **场景图负责提供**：已采用范围内的空间、光源与接触面；选用遮挡、光影处理或运镜时顺图借势，遵从用户明确要求的视觉改动，机位与构图按当前镜头目的及指定职责处理；
*   **分镜文本负责提供**：与人物动机相符的动作时序和节奏、拟音 `<>` 与对白 `{}` 的事件对应关系；具体技法按镜头主要表现目标选用。

### 4. 100% 遵照 Seedance 2.5 官方规范
*   **零表单冒号标签**：杜绝 `生成目标：`、`参考素材职责：` 等机械标签，输出纯净影视化自然段落；
*   **符号专款专用**：音效 `<>`、台词 `{}`、背景音乐 `()`、字幕 `【】`（严格禁止将【】用于普通小标题以防画内印字）；
*   **参数分离**：画幅（16:9）、时长等由接口控制，绝不反写进提示词伪装指令。

## 🚀 安装与使用

### 安装到 Agent 技能目录
将本仓库克隆至你的 Agent Skills 目录（如 `$CODEX_HOME/skills/sd25` 或 `~/.agents/skills/sd25`）：

```bash
git clone https://github.com/wulioo/sd25.git ~/.agents/skills/sd25
```
