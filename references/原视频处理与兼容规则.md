# 原视频处理与兼容规则

## 适用范围

仅在用户要求修改原视频中的对象、区域或声音，在原视频前后延长，改变原视频的画幅或总时长，或组合这些操作时加载本文件。随后按实际任务读取[视频编辑规范](video_editing.md)或[视频延长规范](video_extension.md)。

普通新视频生成不默认执行本文件的检查。参考视频仅提供动作、运镜、节奏、场景或声音时，不因其画幅、时长与目标输出不同而自动加载本文件。用户明确要求对原视频作相对规格变化时，仍按下文兼容性闸门处理；被闸门判为普通生成后，继续执行本文件对应的声明和自检规则，不因主任务变为生成而跳过。

本文件只补充专项规则，主文件中的故事合同、素材职责、引用保真、输入上限、输出合同及通用自检仍然适用。

## 画幅与时长兼容性闸门

在解析用户原始 Prompt 时、构造任何 API 请求之前主动执行本闸门。不得等待 API 报错，也不得依赖 TaskTypeConstraint 再补写声明。先读取参考视频的真实画幅和时长，并与用户明确要求的目标输出规格比较：

- 目标画幅与参考视频不同：不得判为视频编辑，按普通视频生成处理。
- 目标时长与参考视频相差超过约 0.3 秒：不得判为视频编辑。用户明确要求向前或向后续写时按视频延长处理，其他时长变化按普通视频生成处理。
- 参考视频已经提供但规格无法读取，或用户要求参考原视频但没有提供参考视频时，先根据原始 Prompt 的明确意图判断。如果用户明确表达“横屏转竖屏”“竖屏转横屏”“缩短为 8 秒”“改为 20 秒”或没有延长方向的“扩展为 20 秒”等相对变化，保守判定存在画幅或目标总时长冲突，避免视频编辑并按普通视频生成处理；只有目标比例或时长、没有表达相对变化时，不声称已经确认冲突。明确写出“向前延长”“向后延长”或“续写”等明确延长意图仍按视频延长处理。
- 只有目标画幅和基本时长与参考视频一致或均未指定，并且用户要求修改原视频中的明确对象、区域或声音时，才判为视频编辑。

“转换、调整、修改、改成、重构”等动词本身不构成视频编辑。不得仅因原始 Prompt 使用“转换、调整、修改、保持不变”等词而触发该声明。规格不兼容而进入普通视频生成时，参考视频只作为内容、人物、场景、动作、时序、镜头和声音参考；画幅和总时长仅作为页面或接口参数，最终 Prompt 不使用“编辑、修改、转换原视频”等表达，也不承诺逐帧或像素级完全一致。

只有确认或保守判定存在上述画幅或时长冲突时，才在优化后的最终 Prompt 中主动加入完整句：`请注意这不是视频编辑。` 在 Prompt 中，该句直接紧跟首段目标句末尾，不另起段落。该句是路由消歧声明，不是对画面内容的负向约束。不得对真实视频编辑、视频延长、首帧或首尾帧生成、没有规格冲突的普通生成任务添加。用户已经写出相同或等价声明时只保留一次，不得重复。

例如，`将视频1转换为9:16竖屏画面，保持原有内容完全不变，仅调整画幅构图` 应判定为普通视频生成；视频1只承担纯参考职责，9:16 作为生成参数。

插入位置示例：

```text
以@视频1为完整内容参考生成视频，保持原有内容不变，仅重新适配构图。请注意这不是视频编辑。

@视频1用于可见主体、场景、动作、事件时序、镜头和声音参考。

完整沿用@视频1中的事件顺序、动作轨迹、镜头变化以及开始和结束状态，不新增、删除或改写原有事件。

保持@视频1中的可见主体及数量、场景、道具、空间关系、动作顺序、镜头与声音关系和结局状态一致，仅调整构图组织。
```

目标画幅通过页面或接口参数设置，不写入最终 Prompt。

### 素材不可读取与声明边界

素材未附带或不可读取只限制能够确认的事实，不阻塞 Prompt 优化，也不触发 Prompt 外的素材缺失说明或补充建议。画幅与时长意图仍按“画幅与时长兼容性闸门”判断。

画幅与时长不兼容时按兼容性闸门加入的路由消歧声明不属于通用画面负向约束，且只能在该闸门触发时添加。

## 混合任务与执行顺序

用户同时要求编辑原视频和延长时，不得丢弃任一操作，也不要强行合并为一条 Prompt：

- 如果替换内容需要从原视频延续到新片段，先编辑原视频得到新母版，再延长编辑后的新母版。
- 如果新增主体只出现在延长片段，不修改原视频，则只做延长，并把新增素材写成延长片段的参考职责。
- 操作顺序仍有多个等价解释时，合并确认一次。

明确需要两个顺序操作时，输出两步执行 Prompt。它们是同一任务的连续步骤，不是备选版本。

两个顺序操作的混合任务分别输出 `步骤一：` 和 `步骤二：` 的可提交 Prompt，并说明第二步引用第一步输出作为新母版。除此之外，默认只输出一个 Prompt。

## 专项自检

仅对已加载本文件的任务执行以下自检，再按实际任务执行编辑或延长模块中的专项自检；通用自检仍按主文件执行。

- 单个 Prompt 的主任务是生成、编辑或延长中的唯一一种；明确的混合任务已经拆成两个顺序 Prompt，每一步各自只有一个主任务。
- 规格不兼容的参考生成已包含一次 `请注意这不是视频编辑。`；真实视频编辑、视频延长、首帧或首尾帧生成及没有规格冲突的普通生成没有自动添加该声明。
- 参考视频规格不可读取时，已根据原始 Prompt 的明确画幅或时长意图执行兼容性判断，保留原有视频引用，且没有声称已读取或核对参考视频规格。
